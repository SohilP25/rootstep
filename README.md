# Rootstep

Find the step where your agent's failure began.

Rootstep finds which step caused an AI agent to fail. It forks the agent's sandbox at earlier steps, re-runs the agent from each, and measures where the chance of success collapses. Built on Nebius Token Factory (Sandboxes + NVIDIA Nemotron models).

Status: in development for the Nebius x NVIDIA Global AI Hackathon.
